# Flashly

AI flashcards and quizzes from your notes, with spaced repetition, a study
buddy, and an optional community. Free to run.

The app lives in [`ai-flashcard-generator/`](ai-flashcard-generator). Start with
its [README](ai-flashcard-generator/README.md) for features, setup and
deployment.

```bash
cd ai-flashcard-generator
npm install
npm run dev
```

> When deploying (for example on Vercel), set the **Root Directory** to
> `ai-flashcard-generator`.
